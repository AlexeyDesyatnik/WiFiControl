# Continuing or handing off work

- Continue in the current session when the next step depends on the discussion, investigation, or decisions already in context.
- When work moves to another session, person, or workspace, pass along the goal, constraints, decisions and their rationale, relevant files or other primary sources, verification done, and open questions. Use the `handoff` skill for a portable summary when useful.
- Split out independent subtasks when their scope and expected output are clear. Give each subtask only the context and sources it needs, then incorporate its findings in the main task.
