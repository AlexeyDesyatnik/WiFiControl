# WiFiControl

Инструмент для Windows 10 и 11: выбор Wi-Fi-сети в собственном окне и автоматическая смена сетевых настроек под неё — адреса IPv4, DNS и прокси.

Сделан для ноутбука, который за день бывает в нескольких Wi-Fi-сетях с разными требованиями: где-то адрес по DHCP и без прокси, где-то статический адрес с прокси, где-то статический адрес без прокси. Стандартный выбор сети в Windows 11 для этого неудобен, а свои настройки IPv4 и прокси для каждой сети Windows хранить не умеет.

## Что будет уметь

- **Список Wi-Fi-сетей** с уровнем сигнала и защитой, подключение в один щелчок — из окна и из меню значка в трее.
- **Привязки**: каждой сети назначается профиль — именованный набор настроек IPv4 и прокси. Один профиль может обслуживать несколько сетей; для сетей без привязки действует профиль по умолчанию.
- **Переключение**: настройки IPv4 выставляются до подключения к сети, прокси — после, затем проверка. Если подключиться не удалось, прежние настройки возвращаются.
- **Наблюдатель**: если к сети подключилась сама Windows (автоподключение, выход из сна, системное меню), инструмент применяет профиль этой сети.
- **Проводные адаптеры не трогаются**: для них остаётся [NetSwitch](https://github.com/AlexeyDesyatnik/NetSwitch). Инструмент только предупреждает, если интернет сейчас идёт через Ethernet.
- **Признаки проблем**: нет доступа к местоположению (Windows 11 24H2+), включён случайный MAC-адрес, настройки не совпадают с профилем текущей сети.
- **Журнал применений** и отчёт для разбора проблем.

## Требования

- Windows 10 или 11.
- Права администратора. Чтобы не подтверждать UAC при каждом входе в систему, инструмент запускается задачей Планировщика с наивысшими правами ([ADR 0002](docs/adr/0002-tray-app-elevated-via-task-scheduler.md)).
- На Windows 11 24H2 и новее — включённое разрешение «Разрешить классическим приложениям доступ к местоположению»: без него Windows не отдаёт программам список Wi-Fi-сетей и имя текущей сети.

## Где хранятся данные

- Профили и привязки — `%APPDATA%\WiFiControl\WiFiControl.json`.
- Журнал применений и отчёты — `%LOCALAPPDATA%\WiFiControl\`.
- Пароли Wi-Fi инструмент не хранит: они остаются в профилях сетей Windows.
