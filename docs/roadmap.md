# План

Этапы идут по порядку: каждый следующий опирается на ответы предыдущего.

## 0. Разведочная сборка

Только чтение и запись событий, см. [recon.md](recon.md). Итог — заполненная таблица вопросов и поправки к ADR.

## 1. Проверка записи на Windows 11

Отдельный маленький шаг до основного кода: на Wi-Fi-адаптере, через который в этот момент не работаешь, проверить перенесённые из NetSwitch команды — статический адрес на отключённом адаптере и возврат к DHCP на отключённом адаптере ([ADR 0003](adr/0003-settings-written-as-in-netswitch.md)). На Windows 10 этот путь уже проверен.

## 2. Ядро

- Решение, проекты, сборка и тесты в GitHub Actions — по образцу NetSwitch.
- Перенос из NetSwitch: разбор и проверка адресов, настройки прокси, netsh и возврат к DHCP, запись прокси, применение по шагам с откатом, `INetworkSystem` с подменой в тестах, атомарная запись JSON.
- Новое в модели: сеть, уточнение сети, привязка, профиль «Автоматически», профиль по умолчанию, флажок «Не через прокси для частных сетей».
- Хранилище `%APPDATA%\WiFiControl\WiFiControl.json`.

## 3. Окно и переключение

- Список сетей с сигналом, защитой и привязкой; текущее состояние: сеть, адрес, шлюз, DNS, прокси, признаки проблем.
- Переключение по порядку из [ADR 0004](adr/0004-ipv4-before-connect.md), с откатом при неудаче.
- Подключение к новой сети с вводом пароля (создание профиля сети Windows) и к скрытой сети.
- Редактор профилей и привязок; «Профиль из текущих настроек», «Привязать текущую сеть».
- Окно с объяснением и кнопкой, когда нет доступа к местоположению.

## 4. Трей, наблюдатель, автозапуск

- Значок и меню в трее: сети, переключение, «Отключиться», «Временно без прокси».
- Наблюдатель по [ADR 0005](adr/0005-watcher-reacts-to-transitions.md), журнал применений.
- Команда «Запускать при входе» — создание и удаление задачи автозапуска ([ADR 0002](adr/0002-tray-app-elevated-via-task-scheduler.md)); один экземпляр программы.
- Уведомления Windows о результатах применения.

## 5. Выпуск

- Выбор поставки: framework-dependent или self-contained.
- Релизы по тегу `vX.Y.Z`, как в NetSwitch.
- Чек-лист ручной проверки.

## Идеи на будущее

Не обязательства и не порядок работ.

- Импорт профилей из `NetSwitch.json`.
- Уточнение сети по MAC-адресу шлюза.
- Профили и для проводных адаптеров ([ADR 0006](adr/0006-wired-adapters-untouched.md)).
- Явная команда «Интернет через Wi-Fi» — поднять приоритет Wi-Fi метриками.
- Глобальная горячая клавиша для меню сетей.
- Командная строка: переключиться на сеть без окна.
- Перенос записи настроек в службу, если появится нужда работать без прав администратора у пользователя.
