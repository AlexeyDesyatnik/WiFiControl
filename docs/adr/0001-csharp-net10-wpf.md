# C# на .NET 10 + WPF, Wi-Fi через Native Wifi API

Инструмент пишем на C# под .NET 10 (LTS) с интерфейсом на WPF во встроенной Fluent-теме (`ThemeMode`, появилась в .NET 9). Работу с Wi-Fi — сканирование, список сетей, профили сетей Windows, подключение, уведомления о подключении — ведём через Native Wifi API (`wlanapi.dll`). Значок в трее — `NotifyIcon` из WinForms или готовый пакет; выбор — при первой реализации трея.

Главный довод — ядро NetSwitch написано на C# и переносится почти копированием: разбор и проверка адресов, запись IPv4 через netsh, возврат к DHCP без соединения, запись системного и WinHTTP-прокси, применение по шагам с откатом, тесты на подменённой системе. Требования портабельности и поддержки Windows 7, ради которых NetSwitch сидит на .NET Framework 4.0 (ADR 0001 NetSwitch), здесь сняты, поэтому берём современный .NET: async, `System.Text.Json`, свежие библиотеки.

Обёртку над Native Wifi API выбирает [разведочная сборка](../recon.md): первым кандидатом пробуется пакет ManagedNativeWifi, если его не хватит — собственный P/Invoke (нужно около десятка функций).

## Considered Options

- **WinForms на .NET 10** — знаком по NetSwitch, но выглядит чужеродно в Windows 11, тёмная тема пока экспериментальная.
- **WinUI 3 (Windows App SDK)** — самый «родной» вид Windows 11, но заметно сложнее поставка и отладка вне MSIX, а Windows 10 поддерживается с оговорками.
- **Rust + Tauri или egui** — небольшой exe, но ядро NetSwitch пришлось бы переписывать, и проверенное поведение на живых машинах осталось бы только в документах.
- **WinRT `Windows.Devices.WiFi` вместо Native Wifi API** — проще подключение с паролем, но меньше контроля над профилями сетей Windows (режим автоподключения) и над уведомлениями.

## Consequences

- Нужен .NET Desktop Runtime 10 либо self-contained-сборка (порядка 60–70 МБ). Выбор поставки — при первом релизе.
- Перед первой сборкой проверить по официальной матрице поддержки .NET 10, что версия Windows 10 на нашей машине в неё входит.
- Fluent-тема на Windows 10 работает без фирменного фона Windows 11; как это выглядит — смотрим в разведочной сборке, которая сама написана на этом стеке.
