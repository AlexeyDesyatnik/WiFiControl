# Наблюдатель реагирует на смену сети, а не удерживает настройки

Наблюдатель выполняет применение только тогда, когда Wi-Fi-адаптер подключился к сети, отличной от сети последнего применения. Если после этого настройки изменились — руками, через NetSwitch или другой программой, — наблюдатель их не возвращает, а показывает расхождение в окне и в трее с кнопкой «Применить».

Поводы для проверки:

- уведомление о подключении Wi-Fi;
- выход из сна;
- запуск инструмента — если адаптер уже подключён к сети. Применить сразу или только показать расхождение — настройка, по умолчанию «применить».

Подключение, которое запустило само переключение, наблюдатель пропускает: иначе профиль применился бы дважды.

## Considered Options

- **Удерживать настройки** — возвращать профиль при любом отличии. Тогда инструмент воевал бы с NetSwitch и с ручной правкой, например при проверке Ethernet-розетки или настройке роутера.
- **Без наблюдателя, только переключение по команде** — после сна и автоподключений Windows настройки молча не совпадали бы с сетью.

## Consequences

- Нужно помнить последнее применение между запусками инструмента (в журнале применений), иначе после перезагрузки «смену сети» нельзя отличить от повторного подключения к той же.
- Какие уведомления Windows присылает в каждом из поводов и с какими задержками, выясняет [разведочная сборка](../recon.md).
